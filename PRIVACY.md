# Rollout Studio Privacy Policy

**Last updated:** June 2026  
**Contact:** [killscomfort@gmail.com](mailto:killscomfort@gmail.com)

Rollout Studio is a rollout checklist app for music releases. This policy describes how data is handled when you use the app with cloud sync enabled.

## What we collect

When you create an account and use Rollout Studio with cloud sync:

- **Account email** — used to sign in (stored by Supabase Auth)
- **Your rollout data** — project names, task lists, completion progress, and settings you enter in the app
- **Usage signals** (cloud mode only) — sign-in time, last app open, platform (Mac/iPhone/web), and coarse in-app events such as project created or task completed. Used to operate and improve the app, not for advertising.

We do not sell your data. We do not use your data for advertising.

## Where data is stored

Cloud sync is powered by [Supabase](https://supabase.com). Your data is stored in a Supabase project operated for Rollout Studio users. Each account can only access its own projects (enforced by Supabase Row Level Security).

If you use Rollout Studio without cloud sync, data stays on your device only (local storage on Mac or iPhone).

## How we use data

Data is used only to provide the app: syncing your checklists across your devices and preserving your rollout progress.

## Sharing

We do not share your personal data with third parties except:

- **Supabase** — infrastructure provider for cloud sync (see [Supabase privacy policy](https://supabase.com/privacy))
- **When required by law**

## Your choices

- You can delete projects inside the app
- You can stop using cloud sync by using local-only mode
- You can request account or data deletion by emailing **killscomfort@gmail.com**

## Children

Rollout Studio is not directed at children under 13.

We may update this policy. The latest version will live in this repository.
